# Development history

These files preserve the development of **The Plausibility Trap**, originally called **Deal Autopsy**. They include superseded plans, provisional interpretations, and working notes; they do not describe every planned feature or experiment as completed.

The shipped V1 is an exploratory case study of one historical decision across five Work runs: A1, B1, C1, A2, and B2. The larger run grids and additional software in the historical specifications were not completed as part of V1. For the current project presentation, start with the [repository README](../../README.md). The [public methods](../../public/v1/methods.md), [claims and evidence index](../../public/v1/claims.md), and [evaluation rubric](../../public/v1/rubric.md) are authoritative for the published evidence and results. Current repository instructions remain in [AGENTS.md](../../AGENTS.md).

- [Development log](NOTES.md): decisions, failures, corrections, and changes in scope, preserved in chronological order.
- [Build specification v2](deal_autopsy_build_spec_v2.md): an earlier architecture and experiment plan.
- [Build specification v3](deal_autopsy_build_spec_v3.md): the broader Tier 1 architecture and historical Tier 1a design, including unexecuted plans.
- [V1 execution status](V1_STATUS.md): the later decision to ship the five executed Work runs, interpretation boundaries, and final score lock.
- [Deferred work](POST_SHIP.md): ideas and experiment expansions outside the shipped V1.

The specifications, execution status, and deferred-work file retain their historical wording. References to Deal Autopsy and proposed repository layouts describe the project at those stages; they do not indicate a separate current project.
