# Unused replay templates

These empty templates were created for the earlier multi-replay plan. They contain headings and writing prompts, not completed ground-truth records, and are preserved unchanged as development history.

The shipped V1 is the five-run case study described in the [repository README](../../../README.md). Its published transcripts, receipts, trace manifests, rubric, and methods are in [`public/v1`](../../../public/v1/). The experiment's private ground-truth and control files are not part of this archive.
